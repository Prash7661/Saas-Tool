## 📢 Content Copy Assets

### 1. Hacker News "Show HN"

**Title:**
> Show HN: MarkdownTableIO – Instant browser-based CSV/Excel/JSON to Markdown converter

**First Comment:**
> Hey HN,
> 
> I built MarkdownTableIO because I was tired of manually aligning pipe characters (`|`) and dashes (`:---:`) every time I pasted spreadsheet data into GitHub READMEs or technical docs.
> 
> Key highlights:
> - **100% Client-Side Processing:** All parsing runs in pure JS inside your browser. No server uploads, no data retention.
> - **Auto-Padded Pipes:** Auto-calculates column width so your raw `.md` code looks readable even before rendering.
> - **Multi-Format Support:** Paste CSV, TSV, JSON arrays, or upload `.xlsx` files.
> - **Zero Login Required:** Convert up to 10 rows free without creating an account.
> 
> Tech stack: Next.js (App Router), Tailwind CSS, Supabase, Stripe.
> 
> Would love your feedback on edge cases or additional format support!

### 2. Reddit "Value-First" Post Template

**Subreddits:** `r/webdev`, `r/technicalwriting`, `r/github`  
**Title:** I built a lightweight CSV to Markdown table converter because I was sick of manual pipe formatting (No login, 100% browser-side)

**Post Body:**
> Hey everyone,
> 
> Whenever I copy data from Google Sheets or Excel into GitHub documentation or Notion, manually adding `|` pipes and matching header lengths drives me crazy.
> 
> Existing online tools either required registering an account, were covered in spammy ads, or uploaded my raw CSV data to unknown servers.
> 
> So I built **MarkdownTableIO**:
> 
> ⚡ **What it does:**
> 1. Converts CSV, TSV, JSON, and Excel data into formatted Markdown tables instantly.
> 2. Auto-detects delimiters (commas, tabs, semicolons) and strips surrounding quotes.
> 3. Formats Markdown with dynamic spacing so columns align visually in raw code.
> 4. Runs 100% in your browser memory — nothing touches a backend server.
> 
> No login is required for standard conversions. Give it a try and let me know if you run into any formatting edge cases!
